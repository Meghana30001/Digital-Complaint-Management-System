Relational Database Core

Built on a fully normalized RDBMS schema with foreign key constraints, indexing, and optimized SQL queries — showcasing real DBMS concepts like joins, triggers, and stored procedures.

  • Entity-Relationship modelling
  • 3NF normalized tables
  • Cascading updates & deletes
🔍

Real-time Tracking

Every complaint is assigned a unique ID and full audit trail. Citizens and officers see live status changes instantly.

🔐

Role-Based Access

Three-tier access system — Citizen, Officer, and Admin — with SQL-level privilege management and session control.

📊

Analytics Dashboard

Visual reports powered by aggregated SQL queries — complaint trends, category breakdowns, department performance metrics.

🔔

Automated Escalation

Database triggers automatically escalate unresolved complaints beyond SLA thresholds and notify the chain of command.

🏗️

Smart Category Routing

Intelligent complaint routing using predefined category-department mappings stored in lookup tables. Each complaint is automatically assigned to the most relevant handling officer based on department workload and expertise — reducing response time significantly.

Database Design

Engineered on solid DBMS foundations

The system's backbone is a carefully designed relational schema with 8 primary tables, interconnected through referential integrity. Every operation — from filing to resolution — is a structured transaction.

  • users — Citizen & officer profiles with role flags
  • complaints — Core complaint records with FK to user & category
  • categories — Department routing lookup table
  • assignments — Officer-complaint mapping with timestamps
  • status_log — Full audit trail of every state change
  • feedback — Post-resolution satisfaction records
